# كيف تجمع ملفات Stage-2 v4 وData_QC_v2 الأصلية دون بيانات المرضى؟

من داخل المستودع المفكوك على جهاز Linux، نفّذ:

```bash
python scripts/collect_missing_sources.py
```

سينتج ملف ZIP داخل `~/Downloads` يحوي ملفات المصدر النصية من مجلدَي
`Stage_2_rPPG_FineTuning_v4_MorphologyPreserving` و`Data_QC_v2` فقط.
**لا يجمع** صور أو فيديوهات أو HDF5 أو ملفات PPG أو الأوزان المدربة أو
ملفات تقسيم المشاركين ولا يقوم بتشغيل أي تدريب.

راجع محتوى ZIP قبل إرساله للتأكد من عدم تضمين أسرار أو مسارات خاصة.
إذا كانت ملفات final-fitting / independent-inference موجودة في مجلد آخر،
فأرسل شيفرتها المصدرية منفصلة بعد مراجعتها، بدون بيانات المشاركين.
